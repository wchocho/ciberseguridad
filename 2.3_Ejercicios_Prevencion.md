## Sección A: Preguntas de Reflexión y Debate

1. Tienes que auditar una empresa y te ofrecen hacer un *Pentesting de Caja Blanca* o uno de *Caja Negra*. La empresa tiene un presupuesto muy limitado y quiere descubrir la mayor cantidad de fallas graves en el menor tiempo posible. Técnicamente, ¿cuál eliges y por qué?
2. Si aplicas una guía estricta de *Hardening* (como las de CIS) al servidor que aloja la página web de la UTU, desactivando puertos, borrando usuarios y encriptando los discos... ¿Qué principio del módulo 1 (Relacionado con los Sistemas Operativos) estás logrando cumplir rigurosamente?
3. Recibes un reporte de *Threat Intelligence* con un listado de "IoCs" de un nuevo ransomware. Entre ellos hay una dirección IP (`185.10.10.5`) y el "Hash MD5" de un archivo ejecutable. ¿En qué equipos/sistemas de tu red (ej. Firewall, Antivirus, Proxy) cargarías cada uno de esos indicadores para bloquearlos proactivamente?

## Sección B: Role-Play / Laboratorio MITRE ATT&CK

**Escenario:**
Eres el analista del Equipo Azul (Blue Team). Acabas de leer un reporte forense de un ataque a otra escuela, que describe lo siguiente:

> *"Los atacantes entraron adivinando contraseñas, pero cada vez que el servidor se reiniciaba, perdían la conexión. Para solucionar esto, modificaron el **Registro de Windows** (Regedit) agregando una clave en `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` para que su malware se ejecutara automáticamente cada vez que la computadora se encendiera."*

**Tu Tarea:**
1. Investiga rápidamente en la web sobre el marco "MITRE ATT&CK". 
2. De las 14 "Tácticas" generales de MITRE (ej. Reconocimiento, Ejecución, Exfiltración, etc.), ¿a cuál de ellas pertenece específicamente la acción de agregar una clave al Registro de Windows para sobrevivir a un reinicio?
3. ¿Por qué es vital para ti categorizar este comportamiento en MITRE en lugar de simplemente decir "entró un virus"?

## Sección C: Micro-Laboratorio de Arquitectura (DMZ vs VLAN)

Diseño seguro de un Hospital. Tienes los siguientes 3 servidores:
1. **Servidor A:** La página web pública donde los pacientes sacan turnos online.
2. **Servidor B:** El servidor de Historias Clínicas (Base de Datos muy confidencial).
3. **Servidor C:** El Active Directory (El servidor que gestiona las contraseñas de las computadoras de los médicos).

**Instrucción:**
1. Determina exactamente dónde ubicarías cada servidor. Opciones: **Internet, DMZ, o Red Interna (VLAN Segura)**.
2. Basado en tu elección, detalla la regla principal de Firewall que debe existir entre la DMZ y la Red Interna para que el Servidor A pueda validar los turnos en la base de datos sin comprometer la seguridad total del Hospital.
