## Sección B: Role-Play (Incidente de Cloud Computing)

**Escenario:**
Eres el Administrador de Seguridad en la Nube (AWS) para un importante sanatorio médico. Has descubierto que, durante los últimos 3 meses, un "Bucket S3" (una carpeta de almacenamiento en la nube) que contenía miles de radiografías de pacientes estuvo expuesta a internet sin contraseña.

El gerente general está enfurecido y llama a soporte de Amazon exigiendo que les paguen una indemnización porque "Amazon nos hackeó".

**Tu Tarea:**
Basado en el **Modelo de Responsabilidad Compartida**, redacta un breve email formal al gerente general explicándole por qué el reclamo a Amazon no procederá, justificando de quién es exactamente la culpa del incidente y recomendando un paso a seguir inmediato.

## Sección C: Micro-Laboratorio de Misconfigurations (Caja Blanca)

Analiza el siguiente fragmento de una "Bucket Policy" (política de permisos) de un repositorio de almacenamiento en Amazon Web Services (AWS).
Este repositorio llamado `documentos-secreta-empresa` se supone que es únicamente para uso de los gerentes financieros.

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::documentos-secreta-empresa/*"
    }
  ]
}
```

**Instrucción:**
Como Arquitecto de Seguridad, audita este código JSON. 
Identifica exactamente qué campo del código está configurado catastróficamente mal y explica con tus palabras qué puede hacer un atacante si descubre esta política en internet. *(Pista: fíjate bien en el campo `Principal`)*.
